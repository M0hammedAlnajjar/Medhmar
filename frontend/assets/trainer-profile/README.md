# Trainer profile preview

`salim-preview.webp` is an AI-generated portrait of a fictional Omani trainer,
created for the approved Medhmar Trainer Profile design. It is illustrative and
must not be presented as the photograph of a registered trainer. The source image
was converted to WebP for delivery; it contains no UI or text.

The profile, its assignment count, experience and three camel examples are
explicit preview data. No sample ID is passed to backend record routes. The
training action opens the existing Training Log; the registry action opens the
actual camel registry. Sample camel buttons open local read-only dialogs.

Camel photographs are reused from `../marketplace-photos/`; see that directory's
README for attribution and CC BY-SA 4.0 source links. Visible photo credits are
also included on the page. These photographs do not identify the named sample
camels or demonstrate an actual trainer assignment.
