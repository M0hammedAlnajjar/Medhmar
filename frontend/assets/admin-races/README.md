# Race management artwork

`hero.webp` is background artwork generated with the built-in image tool from the user-supplied Race Management reference on 21 October 2026. It is saved locally and requires no third-party image service.

Prompt: extract/recreate only the panoramic top banner; warm ivory sunrise, Oman mountains, date palms, red-bridled racing camel with robot jockey at the center-right, smaller blue/red-bridled camels, pale left side for live headings, subtle geometric ornaments. No text, interface, logo or buttons. The PNG output was encoded as WebP.

The accompanying SVG files are decorative vector landscapes authored for the reference's summary cards, sidebar and empty state. Content, headings, controls, statistics and tables are native HTML. Race thumbnails use the race's saved cover URL with a camel icon when absent or unavailable. The small green total-card badge reports the current open count, not an invented historical change.
