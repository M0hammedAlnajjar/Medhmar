# Race management artwork

`hero.svg` implements the approved “From scheduling to the starting line” header concept: a race calendar and registration credential connect to two numbered camels at a START gate. It contains editable vector paths traced from the approved preview and optimized with SVGO. The image is decorative; the heading and description remain accessible HTML, and the calendar and participant numbers do not represent live race data.

The earlier `hero.webp` remains a legacy packaged asset; the current header uses `hero.svg`.

The accompanying SVG files are decorative vector landscapes authored for the reference's summary cards, sidebar and empty state. Content, headings, controls, statistics and tables are native HTML. Race thumbnails use the race's saved cover URL when available. If a race has no usable cover, the UI uses one of the packaged camel photographs as a deterministic visual fallback so every race row keeps the reference thumbnail treatment; no race data is fabricated. The small green total-card badge reports the current open count, not an invented historical change.
